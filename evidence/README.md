## 给老师看的总览

论文的核心论点是：**AI 研究中存在"看到热门策略 → 不验证 → 照搬"的盲从模式，CoT 提示词是一个典型案例**。三个实验构成递进的论证链：

| 实验 | 文件夹 | 回答的问题 | 核心结论 | 对应论文 |
|------|--------|-----------|---------|---------|
| ① CoT 收益的条件性 | [`01-macro-heterogeneity/`](01-macro-heterogeneity/) | "Let's think step by step" 应该不加验证地当作默认前缀吗？ | **不应该**。收益取决于任务类型和模型规模，32B 以下多数变体退化 | §2–3 |
| ② 前缀的状态初始化效应 | [`02-state-divergence/`](02-state-divergence/) | 只改 prompt 前缀，模型内部会发生什么？ | 三种前缀 → 三条完全不同的隐藏状态轨迹。前缀不是"编码解题步骤"，而是**设定计算动力学的初始条件** | §3 |
| ③ term-first 跨题验证 | [`03-logit-lens/`](03-logit-lens/) | 实验②的单题发现稳定吗？term-first 属于哪种轨迹？ | 延迟承诺型在 5 题上**精确共享 L20 收敛层**；term-first 在 4/5 题上与之吻合 | §3.4 |

### 论证逻辑链

```
案例 1（实验①）：CoT 不是通用增强器 → 排除第一个盲从假设
    │
    ├── "既然 CoT 不是万能的，什么在起作用？"
    │
案例 2（实验②+③）：提示前缀的真正作用是隐藏状态初始化
    │  不是编码解题步骤，不是反思标记的信号
    │
    └── "理解了机制，就能针对性地设计更轻更好的策略"
         → term-first 用 12 token 达到甚至超过重 CoT 的效果
```

### 三个实验的递进关系

1. **实验① 排除旧解释**：CoT 的收益不是通用的 → 盲从"加了就好"是错的
2. **实验② 提出新框架**：前缀 → 隐藏状态初始化 → 三种轨迹类型
3. **实验③ 验证 + 扩展**：跨题稳定性 + term-first 的行为定位

## 每个实验文件夹的结构

```
NN-name/
├── README.md        ← 人类可读说明（实验目的 → 方法 → 结论 → 数据溯源）
├── code/            ← 规范脚本（出图 + 核心分析）
│   └── _dev/        ← 开发中间脚本（保留以备追溯）
├── data/            ← 纯数据（CSV / JSON / npy）
├── figures/         ← 脚本输出的图（多格式）
└── notes/           ← 实验设计讨论、边界分析
```

## 使用方式

1. **了解全局** → 读本文件
2. **深入某个实验** → 进对应文件夹 → 读 `README.md`（开头有"这个实验做什么"的中文摘要）
3. **查数据** → 看 README 里的"数据溯源"表 → 进 `data/` 找对应文件
4. **核证 claim** → 从数据文件 + 对应的生成脚本反向追溯
5. **复现图** → 看 README 里的"复现"节 → `cd code/ && python3 script.py`
